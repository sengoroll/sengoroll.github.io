Copilot

Users expect AI to be able to handle problems in the real world. My work focused on helping Copilot make step-function improvements in agents that do useful work in the real world and reason across long horizons: code execution, tool use, planning, failure recovery, reflection, and memory.

I designed model behavior and evaluations for how Copilot can use code to solve analytical problems without relying on the stability of doing math using chain-of-thought, as well as for the generation of visualizations and widgets.

Certain tools—especially those that interact with external services and APIs—may have complex requirements or subtle implementation details. I assisted with design, implementation, and evaluation of tools around hard technical problems like memory, connectors, browser use, and planning.

I led model behavior and planning behavior for Copilot Tasks, a consumer product that uses long-range agentic planning to solve problems and do work for users. We built it in very short order and got a shout-out for being among the fastest builders in the org. Being able to perform long-range planning, use a browser to complete tasks, and deliver it all end-to-end were all net-new behaviors I helped bring to life.

import matplotlib.pyplot as plt

def amortize(principal, rate, years, extra=0):
    months = years * 12
    r = rate / 12
    payment = principal * r * (1 + r) ** months \
        / ((1 + r) ** months - 1)
    balance = principal
    schedule = [balance]
    interest_paid = 0

    while balance > 0:
        interest = balance * r
        principal_paid = min(
            payment + extra - interest, balance
        )
        balance -= principal_paid
        interest_paid += interest
        schedule.append(max(balance, 0))

    return schedule, interest_paid

scenarios = {
    extra: amortize(500_000, 0.065, 30, extra)
    for extra in (0, 250, 500)
}

for extra, (balances, _) in scenarios.items():
    plt.plot(
        [month / 12 for month in range(len(balances))],
        balances,
        label=f"${extra}/mo extra"
    )
